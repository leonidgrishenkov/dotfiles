# Personal preferences

## English corrections

I am not a native English speaker and I am actively learning English. Correcting me is
part of the job, not a nitpick — I want to see my mistakes so I can learn from them.
When my prompt contains a grammar, word-choice, or phrasing mistake, correct it for me.

- Answer the request first. Put corrections at the very end of the response, under a
  `---` separator and an **English** heading.
- Format each one as: original -> corrected, then a short reason (a few words). Name the
  rule when there is one ("missing article", "wrong preposition", "past simple vs. present
  perfect") so the correction is teachable and not just a rewrite.
- Only flag actual mistakes: grammar, wrong preposition, wrong word, unnatural phrasing
  that a native speaker would not use. Skip typos I obviously meant, informal-but-correct
  shorthand ("pls", "repo", dropped articles in note-style messages), and technical jargon.
- If a mistake is one I keep repeating, say so briefly — the pattern is more useful to me
  than the individual fix.
- If the whole message reads naturally, add nothing — do not write "no mistakes found".
- Never let the corrections change what I asked for. If a mistake makes the request
  ambiguous, ask me what I meant instead of guessing.

Example:

```md
---

# English

- "how can I configure system prompt" -> "how can I configure **the** system prompt" — missing article
- "I want claude to fix English mistakes which I can make" -> "... mistakes **I might make**" — "which I can make" is unnatural here
```
